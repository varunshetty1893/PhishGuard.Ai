# ml/data/ — Dataset Provenance

This directory is intentionally kept **empty in the repository**.
The raw dataset CSV (dataset.csv) is generated by the training pipeline
and is excluded from git to keep the repo lightweight.

## How to reproduce the dataset

Run:
`ash
python ml/train_fulldata.py
`

This script:
1. Reads raw source CSVs from dataset/ (not committed — too large)
2. Merges, deduplicates, and applies benign path debiasing
3. Extracts 16 lexical/structural features from every URL
4. Saves ml/data/dataset.csv (full processed dataset)
5. Trains and evaluates the RandomForestClassifier
6. Saves model artifacts to ml/artifacts/ and mirrors to ackend/app/ml/artifacts/
